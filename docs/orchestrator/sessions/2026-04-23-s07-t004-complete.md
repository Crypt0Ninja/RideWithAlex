## Lessons learned

- **Detail-rich спец дава 4-6× ускорение.** T004 беше най-детайлната задача досега — пълен код на всеки компонент в промпта, explicit координати, точни class-ове. Agent 5 свърши за 15 минути работа, за която estimate-а беше 60-90 min. Извод: колкото повече предварителна работа влага orchestrator-ът в спеца, толкова по-малко време губи downstream агентът (и по-малко error surface).
- **curl-only QA е limit.** Agent не може да тества видео + анимации. За hero-то и бъдещите visual-heavy задачи → винаги добавяй "visual QA by Alex" като пост-task стъпка.
- **Auto-deploy chain работи.** T005 инфра → T004 код → ~1 мин и hero-то е в production. Не е нужно отделно deploy task-а за всяка следваща промяна — само push на main. Страхотен workflow.
