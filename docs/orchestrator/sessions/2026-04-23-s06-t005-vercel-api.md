## Gotchas

1. **Default SSO Protection** — при нов Hobby project Vercel включва "Standard Protection" която изисква Vercel login за всеки visitor. **Винаги** трябва `PATCH` със `ssoProtection: null` за публични сайтове.
2. **Canonical URL shape** — `ridewithalex.vercel.app` (не `ridewithalex-{hash}.vercel.app`, което е deployment-specific). Canonical е стабилен и не се променя при redeploy.
3. **i18n redirect** — `/` → 307 → `/en` е **очаквано** поведение от next-intl middleware (не е бъг). Curl-ът без `-L` връща 307; `curl -L` стига до 200.
4. **pnpm auto-detect** — Vercel видя `pnpm-lock.yaml` и автоматично ползва `pnpm install` + `pnpm build`. Не е нужна ръчна конфигурация на build commands.
