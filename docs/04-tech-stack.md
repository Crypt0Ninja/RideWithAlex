# 04 · Технически план

## Стак

| Слой | Технология | Защо |
|---|---|---|
| Framework | **Next.js 15** (App Router) | SSR/SSG, SEO, i18n, бързина |
| Език | **TypeScript** | По-малко бъгове, по-лесна поддръжка |
| Стилове | **Tailwind CSS v4** | Бърза разработка, малък bundle |
| UI компоненти | **shadcn/ui** + custom | Стабилна основа, пълен контрол |
| i18n | **next-intl** | BG/EN с SSR поддръжка |
| Форми | **React Hook Form** + **Zod** | Валидация, добър UX |
| Съдържание | **MDX** (blog), **JSON** (пакети/услуги) | Без тежък CMS за начало |
| Плащане | **Stripe Checkout** (hosted) | PCI compliance е тяхно, не наше |
| База данни | **Neon Postgres** (safe) или **Supabase** | Резервации, клиенти |
| ORM | **Drizzle** | TypeScript-first, леко |
| Имейли | **Resend** + **React Email** | Модерно, просто, добри темплейти |
| Анимации | **Framer Motion** | За hero и скрол ефекти |
| Анализ | **Vercel Analytics** + **GA4** | Трафик, конверсии |
| Хостинг | **Vercel** | Zero-config за Next.js |
| Images | **next/image** + Vercel CDN | Автоматичен WebP, resize, lazy |

## Защо НЕ WordPress

- Бавен без CDN и cache
- Сигурност (нужни постоянни ъпдейти на plugins)
- Плащанията изискват скъпи plugins или custom код
- По-труден i18n без платени plugins

## Защо НЕ no-code (Webflow/Framer)

- Месечни такси растат с трафика
- Ограничения при custom booking flow
- По-бавно при сложни анимации

## Средства за разработка

- **Node.js 20+**, **pnpm** (по-бърз от npm)
- **Git** + **GitHub** (публично или частно репо)
- **Vercel** акаунт (безплатен tier за начало е достатъчен)
- **Stripe** акаунт (ще ни трябва за плащания)
- **Resend** акаунт (100 имейла/ден безплатно)

## Оценка на месечните разходи (след пускане)

| Услуга | Цена |
|---|---|
| Домейн (.com/.bg) | ~20–40 лв/година |
| Vercel Hobby | 0 лв (ако трафикът е в лимитите) |
| Neon Free / Supabase Free | 0 лв за начало |
| Stripe | ~1.4–2.9% + 0.50 лв на транзакция (само при резервация) |
| Resend Free | 0 лв (100 имейла/ден) |
| Google Workspace (имейл на домейна) | ~15 лв/месец (по желание) |
| **Общо фиксирано** | **~5–20 лв/месец** |

## SEO и производителност (цели)

- Lighthouse score: 95+ на всички категории
- Time to First Byte: < 200ms
- Largest Contentful Paint: < 1.5s
- Първа страница в Google за "сноуборд уроци Банско" / "snowboard lessons Bansko" — дългосрочна цел (3–6 месеца)

## Сигурност

- HTTPS автоматично (Vercel)
- Environment variables за всички ключове (никога в Git)
- Rate limiting на формите (защита срещу спам)
- Stripe webhook signatures
- Content Security Policy headers
- Никога не пазим номера на карти (Stripe прави всичко)
