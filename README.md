# Сайт за сноуборд уроци — Банско

Планиращи документи за уеб сайт на частен сноуборд учител в Банско.

## Резюме на проекта

| Параметър | Стойност |
|---|---|
| Име на бизнеса | **RideWithAlex** |
| Домейн | `ridewithalex.com` (за регистриране) |
| Учител | Alex |
| Локация | Банско |
| Целеви клиенти | Туристи (BG + чужденци) — възрастни, деца, групи |
| Услуги | Частни, детски и групови уроци; пакети 2ч / 4ч / цял ден / седмица |
| Езици на сайта | Български + Английски |
| Основна цел | Онлайн резервация с **30% капаро** + остатък в брой |
| Уникално предимство | Персонален подход |
| Дизайн посока | Минималистичен · черно-бял · lowercase · Readex Pro · editorial |
| Технология | Next.js 15 + TypeScript + Tailwind (SSR/SSG) |
| Краен срок | 2–3 седмици (MVP преди стартиране на сезона) |
